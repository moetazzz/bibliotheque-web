# 📚 Guide Utilisateur — Bibliothèque Municipale

## 1. Accès à l'application

1. Ouvrez votre navigateur (Chrome, Firefox, Edge, Safari)
2. Allez sur : **https://bibliotheque-web-of6e.onrender.com**
3. Connectez-vous avec les identifiants fournis par votre bibliothécaire

## 2. Rôles

### 👤 Membre

Vous pouvez :
- 📚 Consulter le catalogue des livres
- 📤 Emprunter des livres disponibles
- 📅 Réserver des livres empruntés
- 📋 Voir vos emprunts en cours
- 💰 Voir et payer vos amendes
- 🔔 Consulter vos notifications
- 👤 Modifier votre profil

**Règles** :
- Durée d'emprunt : **14 jours**
- Maximum **3 emprunts simultanés**
- Amende : **0,50€ par jour de retard**
- Blocage à partir de **10€ d'amendes**

### 🛠️ Bibliothécaire (Admin)

Vous pouvez tout faire en tant que Membre, plus :
- ➕ Ajouter, modifier, supprimer des livres
- 👥 Gérer les utilisateurs
- 📋 Voir tous les emprunts
- 💰 Gérer toutes les amendes
- 📊 Voir le tableau de bord
- 📜 Consulter le journal d'audit
- 📄 Générer des rapports PDF

## 3. Emprunter un livre

1. Allez dans **Livres**
2. Cherchez le livre (filtres disponibles)
3. Si disponible, cliquez **Emprunter** depuis la fiche
4. La date de retour est automatiquement fixée à +14 jours

## 4. Réserver un livre

Si le livre est déjà emprunté :
1. Cliquez **📅 Réserver**
2. Vous serez **notifié par email** quand disponible
3. Vous avez **7 jours** pour venir l'emprunter

## 5. Retourner un livre

1. Allez dans **Emprunts**
2. Cliquez **📥 Retourner** sur le livre concerné
3. Si retard, une amende est créée automatiquement

## 6. Payer une amende

1. Allez dans **Amendes**
2. Vérifiez votre solde
3. Cliquez **💳 Payer tout**

## 7. Notifications

Recevez des notifications pour :
- ⏰ Rappel 3 jours avant la date de retour
- ⚠️ Retard constaté
- 🎉 Réservation disponible
- 💰 Nouvelle amende

Consultez-les dans **🔔 Notifications** en haut de la page.

## 8. Changer mon mot de passe

1. Cliquez sur votre nom en haut à droite
2. Allez dans **Mon profil**
3. Section **🔒 Changer mon mot de passe**
